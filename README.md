# cookiesGUI

cookiesGUI is a game framework built around LÖVE! It is made in the Godot game engine due to it's powerful GUI tools. It is extremely bare-bones as of now, please consider contributing!

Consider checking out [cookieslib](https://github.com/modleythem/cookieslib), the runtime library that makes cookiesGUI and your LÖVE project work together, as it is currently further in development.
